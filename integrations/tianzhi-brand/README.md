# 天智五号界面品牌

日期：2026-10-28。作者与维护者：yangshaopeng（杨绍鹏）。

用于Harness 0.2.1-rc.2的自有品牌呈现。通过官方sidebar.brand.mark、sidebar.brand.name和conversation.hero.brand.mark插槽提供“天智五号”，停用官方品牌填充；首页自有组件在限定的祖先容器内收起原占位标题与徽章，支持插槽的中间包装；卸载时恢复原有局部样式。浏览器标题保留会话名称并替换产品名。

本插件不修改app.asar，不修改登录、模型名称、计算、任务或权限。底层第三方软件、许可证及作者署名继续保留。卸载品牌插件后撤销插槽、样式和标题观察器；需按实际profile配置重新启用官方品牌行。

与天智五号专业工具插件一起通过官方CLI安装本地tarball。插件只更改呈现，不向模型注入内容；工具标识tianshu_*与预设标识tianshu-distribution保留兼容。现有第三方软件升级后需复核插槽及首页结构。

0.1.1修正了0.1.0首次真实界面中原占位标题仍显示的问题；保留第一次失败核对记录。

0.1.2按界面设计显示“天智五号 配电网潮流计算”：侧栏主名称加粗、说明用小字；首页主名称与小字说明同行，并随窗口高度适度上移，保留输入区的位置。

0.1.3按最新标注取消首页标题的横向和纵向偏移，恢复在输入区上方自然居中。主副标题各自显式指定同一字体，天智五号统一加粗；专业计算逻辑不变。
