刷新：两种方式，别混

  • 🔄 按钮（增量刷新） — 先扫一遍当前界面里哪些数据变了， 只重画变了的那块；没变的一律不动。不会重新加载引擎、不会闪屏。
  • F5 / Ctrl + R（整页重载）— 真正重跑一遍渲染层， 界面卡死时才用。后端进程不重启，聊天记录不丢，但未发送的输入草稿会清。

引擎只在首次冷启动时加载一次（20~40s）；之后无论哪种刷新都不会再加载。

知识库

在「配置 → 知识与经验」可看到本地知识库与 Power-RAG 的真实状态；右上角 ⟳ 重建索引按钮会在新增/修改 knowledge/ 里的文档后重建 BM25 索引。

聊天知识型问题

含「国标 / 标准 / 限值 / 规范 / GB/T / 原理 / 是什么」的问题会优先走知识库，不会被当作潮流计算去跑。计算命令（如「计算 IEEE33」）仍会正常执行潮流。

快捷键

  • F5 / Ctrl + R — 刷新界面
  • Esc — 关闭弹窗
