日期：2026-10-24。维护：yangshaopeng。本文保留专业核心0.10.0-p2、后端/适配器1.8.0的数值支持与验收边界。当前专业入口为0.13.0-p3（后端1.8.2）；P3增加[工程校核与报告](project-engineering.md)和[只读参考比较](reference-comparison.md)，下表保留P2原验收范围；P3受限新增四导体矩阵线路及单相双节点固定Reactor，详见[原生输入扩展](native-input.md#p3受限四导体与固定支路扩展)，其他模型族与历史参考状态保持。

处理指定模型、指定工况下的稳态潮流，不等于任意DSS模型及所有属性均已重放。可靠缺失或矛盾会阻止有效数值发布；工程限值缺依据仍未评估。

## 强制门

1. 冻结源字节、转换清单、工况、请求和求解参数；不自动恢复改模。
2. 主Solve前核频率、可靠设备声明，绑定首次原生状态、被动元件Yprim及固定配置文本（schema1.1，含逐绕组中性阻抗）。
3. 每次主Solve/复算及最终重新核对；CIM导出前后也检查状态和导纳未变。
4. 独立库存核对bus/line/transformer/PCE/辅助元件，逐量验证相量、节点、端口与S=VI*。
5. 完整域检查KCL及复功率守恒。任何门失败不发布有效数值、不保留有效Measurement。

被动门同时冻结实际配置文本与Yprim：原生Yprim有延迟重建缓存，不能仅以它判定求解前参数未变。配置文本保留原始显示精度边界，Yprim采用typed double；两者都不等于逐属性证明所有源矩阵/单位副作用。原生文本精度、未知相别、停用设备及旧声明的明确边界保留。缺getter不回填默认值；停用支路不补零。

## 数值参考

官方MATPOWER8.1在MATLAB对静态解析的原case18及特性派生模型独立求解，用户.m不执行；比较V、端口PQ、发电及损耗。有限源替代理想slack的参数必须由输入合同显式提供，另验证电流和电压近似预算，不暗改用户模型。

三相参考使用LBL公开Modelica模型与作者Dymola回归，冻结来源/版本/条件/误差合同。公开直接V与由公开相量、线路参数推导的I/PQ/损耗分别标注；后者不冒称作者直接发布的电流/功率表或已接第二后端。单/两相、设备及工况补充使用独立解析合同，不能将同引擎自洽或fake getter测试当作独立精度验收。

IEEE原始四节点n2 C相相较7123V超原0.6V门槛仍失败。浮置delta公共电位导致的非收敛/复算失败不跳过；小源阻抗/小反浮导纳派生实验的失败全部保留。IEEE13按原始均匀分布定义细分后，电压和分辨率检查改善，原表完整电流/角度/损耗/系统Q严格对照仍有未通过项，生成条件继续待对齐，不能据此判原表有误。
