# MATPOWER平衡稳态输入

日期：2026-10-23。维护：yangshaopeng。适用版本：专业核心`0.10.0-p2`、后端/适配器`1.8.0`。输入适配版本：`matpower-balanced-pq-1.0.1`。

专业入口接收严格的MATPOWER v2静态字面值子集，生成可追溯的OpenDSS平衡正序等值模型。解析器不执行MATLAB文件、表达式或动态修改，也不导入旧Web服务器和表格转换默认。导入成功只代表输入与转换属于支持范围；实际作业仍须通过原生参数、状态、域覆盖和数值发布门。最终支持证据以对应版本验收记录为准。

## 导入请求

向既有`POST /v1/models/import`提交以下结构，沿用本机Bearer认证；`content_utf8`必须替换为完整原文件文本。不能提交服务器磁盘路径。

```json
{
  "format": "MATPOWER",
  "source_file": "case18.m",
  "content_utf8": "<完整UTF-8静态MATPOWER v2文件文本>",
  "frequency_hz": 50,
  "source_impedance_ohm": {"r": 1e-6, "x": 1e-6}
}
```

频率及有限源R/X必须由调用者明确给定，不能套用50 Hz、100 MVA或首个母线等历史默认。R/X要求非负、有限且不能同时为0。上面的R/X是参考试验的显式条件，并非所有项目的推荐值：MATPOWER数学参考母线为理想源，而OpenDSS使用有限阻抗源，因此模型存在明确的源等值假设；不能声称无条件逐位等价。极小源阻抗还可能使原生源电流读数出现数值条件问题，作业仍须通过逐节点KCL及全部既定门，不会自动更改用户阻抗或放宽检查。是否满足适用误差必须另做对照。

源文件为单个包根`.m`文件名，源文本上限2 MiB；静态检查预算为2000个母线、5000条支路、2000条发电机记录。这些是输入检查预算，未构成该规模的实际性能承诺。原文、完整数值矩阵、转换请求、转换清单及生成的DSS均进入不可变输入包，参与内容身份和完整性核对。原文的换行字节也应保留；准备HTTP请求时不要默默归一原文件。

每个快照绑定转换解释器版本。读取历史快照时先检查容器、原文及原生文件的字节/哈希完整性，再确定相应解释器是否存在；已不支持的版本明确返回能力不可用，列表标为`interpretation_unavailable`。不会使用新版本解释器重写旧包，也不会将完好但解释器不可用的输入误称为文件篡改；发现字节或合同不符仍报完整性错误。已完成历史任务的结果按其原有记录保留。

导入返回真实`snapshot_id`后，按[原生模型作业说明](native-input.md)使用schema 1.1、`existing_snapshot`及明确运行条件提交`POST /v1/jobs`。请求中的运行频率须与导入条件一致；它只用于核对，不指示程序改频率或重新分配负荷。

## 支持的数学范围

要求显式`mpc.version='2'`、正有限`mpc.baseMVA`、非空bus/gen/branch矩阵，并完整给出标准输入列：bus 13列、gen 21列、branch 13列。短行、求解结果附加列、重复赋值及未知扩展不自动补齐或截断。

| 源语义 | 等值与边界 |
| --- | --- |
| 单参考母线与PQ母线 | 恰有一个参考母线、一个在线参考机组，全网通过在运支路连通；不猜电源位置，不聚合参考机组 |
| 参考电压 | 在线参考机组Vg与参考母线Va确定有限源的内电势；参考Pg/Qg是自由平衡量，不被当成固定注入 |
| PQ负荷 | 非负Pd与明确Qd映射为恒功率Load；纯Q零P负荷及会触发原生极小kW规范化的输入明确拒绝 |
| 非参考发电机 | 在线正Pg、明确Qg映射为固定PQ Generator；其原生kVA取该运行点视在功率，仅为等值参数，不是铭牌或认可限值 |
| 母线GS | 非负电导映射为恒阻抗有功负荷；负电导拒绝 |
| 母线BS | 正BS映射固定Capacitor、负BS映射固定Reactor，按额定电压下MVAr换算；其输出随电压平方变化，不冒充恒Q |
| 普通支路R/X | 按`Zbase=BASE_KV_LL²/baseMVA`转为欧姆；要求非负且总串联阻抗非零 |
| 支路B | 映射为两端固定导纳π充电，正负电纳分别使用Capacitor/Reactor；普通支路两端各B/2 |
| 无相移两绕组变比 | 支持wye-wye平衡等值，from侧非标tap；TAP=0按MATPOWER规定解释为1。跨基压或显式正TAP使用该等值 |
| 变压器阻抗基准 | 原生kVA使用系统baseMVA，两个绕组各承担`Rpu×50%`，总漏抗`Xpu×100%`；不把rateA当阻抗基准或铭牌容量 |
| 带tap支路B | from端充电按`B/(2×tap²)`折算，to端B/2；明确零励磁、无载损耗及anti-float项，不猜原设备结构 |
| 停运支路与机组 | 原行及参数完整保存在清单，标明无本次稳态注入/导纳，不伪造停用设备的有效电气读数 |

Load与固定PQ Generator在本等值域内保持给定功率，显式取消原生低压模型切换；数学适用域为`0 < voltage_pu < 1000000`，不是允许电网运行到该范围的工程结论。Loadmult/Genmult固定为1，设备运行点已由原矩阵给定。

## 明确不支持或未应用的内容

- PV调压母线、孤岛/多个参考源、非零相移、非零P-Q能力曲线、爬坡及参与因子、一般MATLAB表达式和动态单位换算，均明确拒绝。不能只读取前半段矩阵而丢掉后面的换算代码。
- bus初值VM/VA及非参考PQ机组的VG保留；除参考角度外，不作为PQ母线固定电压约束或PV调压指令。负荷与发电运行点不会因初值变化被暗改。
- VMAX/VMIN、RATE_A/B/C、角差限值以及机组P/Q上下界保留，当前为非强制限值的AC稳态计算，不执行OPF、PV↔PQ切换或经济调度。缺少工程确认时仍未评估。
- mBase是机组标幺基准，不作真实铭牌容量；原生默认NormalAmps等也不是项目认可的工程判据。gencost、areas及区域/分区信息保留，未进入本次潮流控制方程。
- 原生Vsource的basekV仍受通用属性文本精度限制，高精度源基压可能在运行期读回门被拒绝；不能截断原输入来制造匹配。可解析的正有限数值不等于该数值已获原生运行期验收。

转换清单逐行记录原矩阵/行号、目标对象、端口和充电支路、量纲及未应用项。不能因数值上能求解就把这些未应用内容宣称已校核。

## 相别与结果

MATPOWER只提供平衡正序信息。生成模型的三条相线、节点1/2/3/0、等值wye连接和线路零序参数均是计算嵌入，不是恢复的真实相别、接地或负序/零序模型。

专业结果明确`balanced_equivalent=true`、`physical_phase_mapping=false`；保留计算节点、导体、实际V/I/PQ及`equivalent_phase_label`，物理`phase`为null，不生成声称真实相别的Measurement。JSON/CSV中的计算相份额不能作为三相不平衡验收证据。旧归一化诊断同样须按平衡等值范围阅读。

## 公开参考

本子集以固定MATPOWER 8.1提交中的[case18](https://github.com/MATPOWER/matpower/blob/1a828c7af590714499284e36ee9c81273388c594/data/case18.m)作为正向参考候选；它含非连续母线编号、固定电纳、π充电及跨电压等级变压器。参考通过静态读取原矩阵，再将数组交给官方MATPOWER `runpf`，不执行输入`.m`。数值对照按预先冻结的母线电压/角度、支路双端有符号P/Q及串联有功损耗合同进行。

非参考固定PQ机组、GS、负电纳及非单位tap等使用单独标明的受控派生样本扩展验证，保留相对原案例的逐条修改清单及独立MATPOWER参考，不能冒称未经修改的官方案例。有限源测试条件与每份参考对照合同分别冻结。

原版case4_dist含PV调压，case22含动态单位换算，作为支持边界负例，不能因此宣称任意MATPOWER案例均已支持。公开参考合格也不替代认可工程模型对照，更不取消原IEEE参考的独立失败或其他未验事项。
